# 云函数对象级权限审计

| 云函数 | 外部对象输入 | 权限结论 |
|---|---|---|
| `loginOrRegister` | 无 | 仅使用可信 `OPENID`，不接受用户对象 ID。 |
| `bindPhone` | 微信手机号授权码 | 手机号由微信 OpenAPI 解码；账号合并不信任前端用户 ID，并记录可恢复的合并操作。 |
| `dataApi` | 项目、支出、附件、配对码 | 项目和支出均验证 `userId`；附件同时验证用户、支出、原文件标识和云路径；级联删除使用事务。 |
| `ocrReceipt` | `fileID` | 已验证登录用户及 `attachments/{userId}/` 路径；未配置 OCR 时不读取图片内容。 |
| `exportExcel` | `projectId` | 导出前验证项目归属；输出按用户和项目隔离并登记七天有效期。 |
| `syncApi` | 配对、令牌、同步实体、附件 | 设备令牌哈希存储；所有读写按令牌对应 `userId` 过滤；更新校验版本和对象归属；附件下载再次校验。 |
| `maintenance` | 定时事件 | 要求云环境 `MAINTENANCE_SECRET` 与定时事件密钥一致，不接受普通小程序调用。 |

## 已修复的高风险路径

旧版附件替换直接使用前端 `_id` 更新数据库，可能把其他用户附件改绑到当前支出。现在 `_id` 必须存在于当前用户、当前支出的已有附件集合中，且已有附件的 `fileID` 不允许被前端替换。对应回归测试位于 `wechat-miniprogram/tests/domain.test.js`。

## 剩余运营要求

- 数据库集合应关闭客户端直读直写。
- HTTP 网关必须启用 HTTPS、请求体限制和配对接口限流。
- 定期检查 `dead_letter` 清理任务和失败的 `merge_operations`。
- 令牌、手机号、配对密钥和附件内容不得写入日志。
